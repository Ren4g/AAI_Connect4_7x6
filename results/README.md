# Results

This directory stores non-match evaluation and training artifacts:

- `solver_eval*`, `solver_depth_curve*`, and `solver_checkpoint_comparison*`: absolute solver measurements.
- `training_*` and `solver_labels_*`: CNN training reports and exact-label cache.
- `cnn_first_errors*`: solver-based CNN loss diagnosis.

Game-vs-game benchmark summaries and replay logs live under `benchmarks/`.
